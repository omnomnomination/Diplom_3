# Diplom_3

# Дипломный проект. UI-автотесты Stellar Burgers

## Что проверяем
**Основная функциональность:**
- Переход по клику на «Конструктор».
- Переход по клику на раздел «Лента заказов».
- Открытие всплывающего окна с деталями ингредиента.
- Закрытие всплывающего окна по крестику.
- Увеличение счётчика ингредиента при добавлении в заказ.

**Лента заказов:**
- Увеличение счётчика «Выполнено за всё время» при создании заказа.
- Увеличение счётчика «Выполнено за сегодня» при создании заказа.
- Появление номера заказа в разделе «В работе».

## Установка и запуск
1. Установите зависимости:
   `pip install -r requirements.txt`

2. Запустите все тесты (в Chrome и Firefox):
   `pytest -v`

3. Запустите тесты с формированием отчета Allure:
   `pytest --alluredir=allure-results`

4. Посмотрите отчет Allure:
   `allure serve allure-results`
